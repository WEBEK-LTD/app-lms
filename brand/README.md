# Yallapp brand files

| Folder | Contents |
|---|---|
| `logo/` | The "yallapp." wordmark as SVG: primary (Midnight), reversed (Ivory), white, black, and versions on white, Ivory and Midnight backgrounds |
| `icon/` | The "y." mark on dark, white and Ember backgrounds (square, rounded, circle), SVG plus a 1024 px PNG |
| `stores/` | App Store icon (1024), Google Play icon (512) and feature graphic (1024 × 500), Android adaptive icon layers |
| `favicon/` | Favicons, `site.webmanifest` and the `<head>` snippet for the website |

Text in every SVG is converted to outlines, so no font is needed to display
them. Colors, type and usage rules are in [`docs/BRAND.md`](../docs/BRAND.md).
