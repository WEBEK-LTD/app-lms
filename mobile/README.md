# Yallapp app (Flutter)

The white-label app every client gets, built once per client with their own
name, icons, colors and website.

```
mobile/
  core/            shared: config, theme, templates, sign-in, API client, storage
  modules/lms/     Academy screens
  modules/store/   later (WooCommerce)
  modules/booking/ later
```

Built in Phase 3. See [`docs/ROADMAP.md`](../docs/ROADMAP.md) and the API
contract in [`docs/api/openapi.yaml`](../docs/api/openapi.yaml).
