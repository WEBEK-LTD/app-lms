Each `*.dc.html` file is one screen. The canvas is the source of truth; these
copies are for reference while building.

| `Lesson`, `TextLesson`, `EmbedLesson`, `Quiz` | App: video, HTML and iframe lessons, quiz |
| `Profile`, `Settings` | App: account and settings |
| `Admin` | Plugin settings page in WordPress admin |
| `Saas*` | yallapp.com.tr: website, sign-in and sign-up, client dashboard, super admin, guides, legal pages |
